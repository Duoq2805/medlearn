# Project Summary

Medvora is an AI-powered medical learning platform for university students.

Main system areas:
- disease learning
- disease versioning
- reviewer moderation
- AI-assisted study support
- secure authentication

Main architecture goals:
- scalable backend
- reusable workflows
- maintainable services
- AI-assisted development
- token-efficient engineering workflow

Main technical standards:
- Spring Boot
- layered architecture
- DTO pattern
- ApiResponse wrapper
- JWT authentication
- PostgreSQL
- MapStruct

Main development philosophy:
- preserve architecture consistency
- reuse existing patterns
- avoid unnecessary complexity
- compress reusable knowledge into summaries
- reduce repeated repository analysis

Repository intelligence strategy:
- CLAUDE.md stores global behavior
- architecture docs store reusable system reasoning
- workflow docs store business flow knowledge
- summaries store reusable session memory
- diagrams store visual architecture understanding
